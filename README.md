# CueVault — 8 Ball Pool Storefront

A responsive, high-converting digital storefront for 8 Ball Pool tools, plans, coin bundles, and gameplay demonstrations.

## 🚀 Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile with dark aesthetics and smooth micro-interactions.
- **Embedded Gameplay Demonstrations**: H.264 MP4 videos showcasing AI tool capabilities and cue ball trajectory prediction.
- **Multi-Currency & Multi-Language Support**: Built-in support for multiple currencies (USD, EUR, GBP, CAD) and languages (EN, DE, FR, ES).
- **Express Checkout & Direct WhatsApp Ordering**: Integrated modal checkout supporting PayPal, Apple Pay, Card, and WhatsApp order routing.
- **Customer Proofs & Testimonials**: Genuine screenshots showing delivered coins, purchase receipts, and repeat customer trust.

## 🌐 Deploy to GitHub Pages

1. In this repository, navigate to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Under **Branch**, select `main` (or `master`) and folder `/(root)`.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repo-name>/`.
